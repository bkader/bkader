# Hi, I'm Kader Bouyakoub 👋

**Independent web developer · Creator of CiSkeleton · Founder of Ianhub**

I build web applications, developer tools, and modular systems designed to give developers the freedom to create without unnecessary complexity.

My work combines a long-standing interest in software engineering with a practical approach to architecture, maintainability, and performance.

> I am specialized in anything as long as I can learn it.

## What I work on

### CiSkeleton

**The Power to Build, The Freedom to Create.**

[CiSkeleton](https://github.com/ciskeleton) is a modular PHP framework and the foundation of my work on extensible web applications.

I'm building its ecosystem around independently installable modules, plugins, themes, languages, and other components.

The goal is simple: provide a solid foundation while leaving application-specific functionality to the components that need it.

- [Explore CiSkeleton](https://github.com/ciskeleton)
- [Visit Ianhub](https://www.ianhub.dz)

### Ianhub

[Ianhub](https://www.ianhub.dz) is my professional brand for web application development.

I focus on building practical solutions, reusable components, and tools that help developers and businesses create applications suited to their needs.

## My approach

- **Modularity:** Keep components independent and responsibilities clear.
- **Simplicity:** Prefer straightforward solutions over unnecessary abstractions.
- **Maintainability:** Write code that remains understandable as projects grow.
- **Performance:** Optimize where it matters without sacrificing readability.
- **Openness:** Encourage collaboration, reuse, and community contributions.
- **Continuous learning:** Explore unfamiliar technologies and turn what I learn into practical solutions.

## Technologies

My primary development stack includes:

- **Backend:** PHP 8+, CodeIgniter 3, custom framework architecture.
- **Frontend:** JavaScript, jQuery, HTML5, CSS3, Bootstrap.
- **Data:** Relational databases, caching, and application storage.
- **Tools:** Git, GitHub, and automated development workflows.

I value understanding the underlying technology rather than relying on tools I cannot explain or maintain.
